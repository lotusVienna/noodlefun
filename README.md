# Noodle Fun Website V1.5

Refaktorierte statische Website als Grundlage für einen späteren eigenen Online-Bestellbereich.

## Struktur
- index.html – Hauptseite
- styles.css – zentrales Design-System
- script.js – Mobile Navigation
- assets/ – bestehende Bilder hier ablegen
- pages/impressum.html – Platzhalter
- pages/datenschutz.html – Platzhalter

## Vor dem Livegang
1. Bestehende Logo-/Menübilder in `assets/` kopieren.
2. Verifizierte Wolt- und Foodora-URLs eintragen.
3. Impressum und Datenschutz mit echten/geprüften Angaben ersetzen.
4. Menü-PNGs möglichst in WebP/AVIF konvertieren und Pfade aktualisieren.
5. JSON-LD anhand der verifizierten Geschäftsdaten prüfen.

## Zukunft
Noch kein Warenkorb, Login, Datenbank oder Zahlungsanbieter. Die Online-Bestellsektion ist bewusst als späterer Einstiegspunkt vorbereitet.
